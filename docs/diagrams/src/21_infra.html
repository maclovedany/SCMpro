Railway Cron — Engine
Root: engine · */10 * * * * · uv run engine tick — fn_tick 의 유일한 호출자
Dockerfile: python:3.12-slim + libgomp1(lightgbm 런타임) + uv. 의존성·소스 레이어 분리로 캐시 유지
크론 잡이라 restartPolicyType = NEVER. 자동 런이 도는 달은 메모리 2GB 이상 (D-049)

Pro / Micro 8GB. 2026-09-14 디스크 장애 후 이전 (D-045)
