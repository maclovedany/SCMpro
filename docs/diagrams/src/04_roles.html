SYSTEM OVERVIEW · §6

역할별 사용법

여섯 역할이 매달 무엇을 하고 어느 화면을 여는가. 권한은 역할로 DB 에서 강제되므로 보이는 메뉴가 곧 할 수 있는 일이다.

SCM 품목담당자
매달 — 데이터 업로드 → 예측 확인 → 발주 계획 생성 · 검토 · 확정 → 입고 · 배정 처리 → AI 감시 알림 대응
주로 보는 화면
데이터 업로드 예측 발주 계획 재고 배정 AI 감시 품목
시스템에서 가장 오래 머무는 역할. 발주량을 확정 하는 사람.
SCM팀장
매달 — 승인함 결재(발주 계획 · Bulkdeal · 우선 배정 · AI 예측 조정 · AI 감시 발주 제안), 대시보드 감독, 예측 정확도 · 사후 채점 확인
주로 보는 화면
승인함 대시보드 예측 발주 보고서
승인이 나야 제출 OL 이 기록되고 다음 달 Flex 기준이 잡힌다.
영업
매달 · 수시 — 가용재고 조회 → 검토 요청 → 30일 안에 수주 확정, 수요자료 제출
주로 보는 화면
영업 주문 일정 · 제출
가용재고 = 현재고 − 임시배정 − 확정배정 − 승인대기.
임시배정은 30일이 지나면 자동으로 풀린다.
마케팅 · 서비스
매달 — 수요자료 제출, 추가수요(수급회의) 입력, 배정 결과 확인
주로 보는 화면
일정 · 제출 추가 수요 알림
제출 마감은 전월 말일 하루 전. 미제출이면 10분마다 독촉이 간다.
사업강화
매달 · 수시 — 주문 우선순위 지정, GC 별도 확인분 입력, 수요자료 제출
주로 보는 화면
배정 우선순위 추가 수요
우선순위를 바꾸면 입고 시 자동 배정 순서가 그대로 따라간다.
관리자
상시 — 계정 · 역할, 시스템 설정(리드타임 · DoS · Flex · 알림 · 자동 런 · AI 감시 · 보존), 공급처 · 공휴일 · EOL, AI 통계
주로 보는 화면
관리 그룹 전체
설정은 비개발자 UI 로 바꾼다. 코드 수정 없이 규칙 값이 바뀐다.
역할과 무관하게 모두가 쓰는 것
AI Agent 패널
모든 화면 우측에서 드래그로 폭을 조절하는 채팅. 시스템 데이터를 도구로 직접 조회해 근거와 함께 답한다.
내 권한으로 조회하므로 내가 못 보는 데이터는 AI 도 답하지 않는다.
알림 · 대시보드
시스템 알림은 화면과 이메일 양쪽으로. 대시보드는 역할별 KPI 5개와 재고 건전성 · 품절 리스크 ·
발주 사이클 · 예측 신뢰도 묶음을 보여주고 전부 드릴다운된다.
역할은 가입 트리거가 만든다 — app.profiles.role 7종 (item_manager · scm_lead · sales · marketing · service · biz_enable · admin). 역할별 단계별 시나리오와 FAQ 는 docs/08-user-guide.md.
