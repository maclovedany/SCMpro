# 용어집

최종 갱신: 2026-09-13 · 출처: 데이터 설명.docx, 회의록, stage1.md, 01-schema.sql

| 용어 | 정의 | 비고 |
|---|---|---|
| **OL (Outlook)** | 영업이 기종별 판매계획 수량을 취합해 물류에 공유하는 수량. 제품·부품 모두 존재 | `Sales OL` = 영업 원안, `SCM OL` = SCM이 조달수요·트렌드 반영해 조정한 값 |
| **기준 예측** | 이 시스템이 생성하는 예측치. 장기적으로 Sales OL·SCM OL 을 대체 목표 | D-002: 당분간 3종 병행 표시 |
| **ACT** | 실적 출고 수량 | `fact_mc_plan_actual.act` |
| **필요월도** | 해당 재고가 실제로 필요한 월 (고객 출고 예측월) | |
| **DoS (Day of Sales)** | `월말재고 ÷ 월평균사용량(최근 6개월) × 30`. 월말 재고 목표 일수 | 통상 30일. 기종별 상이하게 갈 예정 |
| **목표 DoS 일수** | 품목별로 관리하는 DoS 최소 기준 | 미설정 시 발주 확정 차단 (R-OQ) |
| **Flexibility rule / Flex rule** | Supplier 에 제출한 OL 대비 발주 수량 변경 허용 범위. 첫 월 ±20%, 이후 2개월 ±30%, 4~6개월 후 제한 없음 | |
| **MOQ** | 최소 발주(구매) 수량 단위. 올림 처리 | 미설정 시 1 |
| **MC** | Machine, 기계 본체 | |
| **DT** | Digital Technology — A3 복합기 | |
| **GC** | Graphic Communication — 대형 인쇄기 | 건별 영업 확인 필요 |
| **PRT** | Printer — A3/A4 프린터 | MOQ 적용 필수 |
| **Neutral** | 실제 수입되는 중립 사양 본체 코드 | `bridge_mc_cap.neutral_item_code` |
| **SCC** | Neutral 본체에 교체 투입되는 구성품 (국가/사양 특화) | `bridge_scc_config` |
| **CAP (부번)** | 판매 구성 단위 코드. 주문은 CAP 로 들어오지만 실제 출고는 Neutral+SCC+필수옵션 | `bridge_mc_cap`, `bridge_cap_option` |
| **옵션 필수품 / 필수 옵션** | 특정 기기·옵션 출하 시 반드시 포함되는 옵션. 기계와 1:1 관리 | `bridge_cap_option.role = MUST_OPTION` |
| **장착률** | 기기 판매 시 해당 옵션이 함께 나가는 비율. 기종별로 다름 | 이력 데이터 미수령 (Q-001) |
| **Common품** | 복수 기종에 공통으로 쓰이는 옵션/부품/소모품 | `bridge_option_model.common` |
| **BOM** | 기종별 구성 자재 명세 | `bridge_bom` |
| **XCN** | 설계변경으로 부품 코드가 바뀌는 것. 연계 코드 전체 합산으로 트렌드 확인 | `bridge_xcn` |
| **HOC (Code)** | XCN 체인의 최종 발주 코드. 발주는 HOC 로만 | `dim_item.hoc_code` |
| **Bulkdeal** | 이벤트성 대량 주문. 트렌드를 무시하게 만들므로 별도 리스트업·가산 | SCM팀장 승인 필요 |
| **재수출** | 과잉재고·타 거점 부족 시 SPOT 으로 타국 수출. 판매 아님 → 사용량에서 제외 | |
| **기타 출고** | 트러블·사고·폐각 등. 재고 감소로만 인식, 산출에서 제외 | |
| **평균 사용량** | 3M / 6M / 12M 기간별 평균 사용량 | DoS 는 6M 고정 |
| **전월도 재고** | 전월 말 마감 재고 수량 | |
| **수급회의** | 수요 확정을 위한 월 1회 정기 회의 | 결과는 SCM 담당자가 대신 입력 |
| **SFDC** | Salesforce 영업 파이프라인 | 확률만 높은 건은 반영 안 함 |
| **System / FX-LIVE** | 산출된 발주량을 최종 FIX 해 Supplier 에 제출하는 시스템 | 절차 ⑨ |
| **EOL** | End of Life — 판매 종료. 출시 후 약 5년 | 후속기 등장 |
| **EOS** | End of Service — 부품·소모품 공급 종료. EOL 후 약 5년 | |
| **MIF** | Machines In Field — 설치 기반 기계 대수 | 이번 범위 제외 (D-005) |
| **임시배정** | 영업 주문 `검토 요청` 시 30일간 재고를 확보하는 것 | R-AL |
| **확정배정** | `수주 확정` 또는 수동 확정으로 전환된 배정. 30일 만료 없음 | R-AL |
| **승인대기 확보수량** | 수동 우선배정 팀장 승인 대기 중 잠시 확보한 수량. 임시/확정배정 아님 | R-AL |
| **FY (회계연도)** | 4월 1일 시작. FY25 = 2025-04 ~ 2026-03. 모든 연 단위 집계 기준 | D-015, R-FC-08 |
| **AI Agent** | 전 화면 상단 버튼으로 여는 gpt-5-nano 채팅. 대화 저장·맥락 유지·도구 호출 | D-017, R-AI |
| **백테스트 라운드** | 학습 FY 구간 → 다음 FY 예측·평가. 초기 FY23+24 → FY25 | D-016, R-FC-40 |
| **가용재고** | 현재고 − 임시배정 − 확정배정 − 승인대기 확보수량 | 영업부에 보여주는 값 |
