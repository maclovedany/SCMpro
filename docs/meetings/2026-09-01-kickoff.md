# 킥오프 미팅 요약

파일: `회의록.docx` (2026-09-01) · 녹취 원문은 수정 금지. 잡담·오인식 구간은 제외하고 업무 내용만 정리.
참석: SCM 실무자 여러 명(참석자 3·4 가 주 설명자), 개발/컨설팅 측(참석자 2)

## 논의 내용

### BOM / 필수 옵션 / CAP
- 실제 수입하는 건 Neutral 본체. Neutral + SCC + 필수옵션이 결합돼 CAP(판매 단위)가 된다. 예시로 든 기종은 7개 하위 아이템으로 구성.
- 주문·수요는 CAP 코드로 들어오지만 실제 나가는 건 하위 아이템. "스탠다드 + 빨간색(필수옵션)까지는 무조건 같이 나간다."
- 같은 옵션이 어떤 기종에서는 필수, 다른 기종에서는 별도 옵션으로 걸려 있어 합산이 어렵다.
- 거의 같은 기계인데 DT 와 GC(BC) 코드 체계가 달라 정리 필요.
- BT = HD 쪽, DC/GC = 대형기. 프린터에는 SCC 구조 없음.

### Bulkdeal
- 특정 고객 대량 거래가 들어오면 트렌드가 다 무너짐. 기존 로직 위에 수량을 그냥 **플러스**. 별도 리스트업 필요. 예측 계산에서는 제외.

### DoS
- 발주 시 월말 재고를 0으로 맞추지 않고 DoS 만큼 여유를 둠. 현재 전 품목 **30일 고정**이나 기종별로 다르게 하고 싶음 (월 500대 기종 → 15일, 월 1대 기종 → 60~90일). DoS 값 바꾸면 발주량이 바뀌는 기능 원함.

### 제외 출고
- 재수출(타국 SPOT), 기타 출고(트러블), 데모 투입 후 반환 등은 판매가 아니므로 사용량에서 제외. 카테고리 분리해서 손실 리포트에 활용.

### 부품 XCN
- 설계변경·원자재·공장 변경으로 코드가 계속 바뀜. 같은 부품이 A→B→C→D. 각 코드에 재고가 흩어져 있어 합산 필요(3+2=5). 발주는 최종(HOC) 코드로.
- 부품 파일이 커서 CSV 로 제공. 파일의 HOC 열은 최신이 아닐 수 있음.

### 옵션 · 장착률 · Common
- 장착률: A기종 40%, B기종 20% → 각각 판매대수 × 장착률 후 합산. **장착률 시스템은 별도이나 과거 이력 없음**, 그때그때 만들어 씀 → 정리해서 추후 제공.
- 옵션 출고 트렌드는 2020~2021년부터 축적. 여러 기종에 공용인 옵션(Common) 있음.

### 소모품
- 트렌드만 보면 되어 가장 심플하지만, 신기종이 구기종 소모품을 그대로 쓰는 경우가 있어 범위가 넓음. HOC 도 드물게 있음.
- EOL(출시 ~5년 후 판매 종료) → EOS(EOL ~5년 후 서비스 종료). 총 ~10년 수명. Common 소모품은 구기종 감소분만큼 신기종이 늘어 총량 유지되기도, 소모품이 다르면 급감/급증하기도. 비율이 일정하지 않아 가장 예측 어려움. 사람마다 조정 편차 큼(막판 사재기 등).
- 기종별 EOS 일정은 정리된 시트 있음(Google Drive).

### 범위
- **MIF(설치 기반 대수)** 는 매달 바뀌고 복잡해 이번엔 제외 (D-005).
- 용어 정의 문서를 회사 측이 별도 제공 → `데이터 설명.docx`.
