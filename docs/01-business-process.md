## 1. 회사와 발주 대상

해외 공급처 5곳(D-001)에서 기계·옵션·부품·소모품을 수입해 국내 판매. 발주 대상 카테고리와 소요량 산출 방식:

| No | 카테고리 | 발주처 | 소요량 산출 방식 | 주요 생산지 |
|---|---|---|---|---|
| 1-1 | MC: A3 복합기 (DT) | 해외 | OL + 조달 수요 예측 | 베트남, 중국 |
| 1-2 | MC: A3/A4 프린터 (PRT) | 해외 | OL + 조달 수요 예측 + 트렌드. **MOQ 필수** | 베트남, 중국, 홍콩 |
| 1-3 | MC: 대형기 (GC) | 해외 | OL + **별도 영업 확인** (건별) | 일본, 중국 |
| 1-4 | 옵션 | 해외/국내 | MC별 필수옵션 수량(기기수량 연동) + 사용 트렌드(장착률) + 별도 요청수량. MOQ 필수 | 베트남, 일본, 중국, 국내 |
| 1-5 | SW 옵션 | Download | Order to Order, 즉시 Web 발행 → **예측 대상 아님** | — |
| 2 | 부품 | 해외/국내 | 과거 Trend + 월평균 사용량(6M) + 계절수요 | 일본, 네덜란드, 미국, 국내 |
| 3 | 소모품 | 해외/국내 | 과거 Trend + 전년동월 + 월평균(6M) + 시즌수요 | 일본, 베트남, 중국, 홍콩, 유럽, 미국, 국내 |

리드타임은 Supplier 별로 상이 (설정값, Q-002).

## 3. 옵션 소요량 산출 흐름 (가장 복잡)

1. 기계 발주량 확정 (⑥)
2. CAP → 필수 옵션 전개: 기계 N대 = 필수옵션 각 N개 (`bridge_cap_option`, R-BOM)
3. 선택 옵션: 기종별 `판매대수 × 장착률` 합산 (장착률 이력 미수령, Q-001)
4. Common 옵션은 기종별로 나눠 세면 이중계상 → 옵션 코드 기준으로 합산 (R-BOM)
5. 별도 요청수량(수급회의 승인, Bulkdeal) 가산
6. 옵션 전월도 재고·입고예정 차감 → DoS·Flex·MOQ 적용

## 4. 조직과 권한

| 역할 | 하는 일 |
|---|---|
| SCM 품목담당자 | 목표 DoS, 배정방식, 최종 발주량 **확정**. 수동 확정배정. 수급회의 결과 입력 |
| SCM팀장 | 위 항목 **승인**. 수동 우선배정·Bulkdeal 추가발주 승인 |
| 영업부 | 주문 등록(검토 요청 → 수주 확정). 가용재고 조회 |
| 마케팅부 | 용지·카드리더기 재고 조회. 수요자료 제출 |
| 서비스부 | 소모품 재고·긴급발주 현황 조회. 수요자료 제출 |
| 사업강화부 | 임시배정 우선순위 조회·변경 |
| 관리자 | 공급처·법인·리드타임·출항일·OL 선행개월 등 설정 |

## 5. 목표와 KPI

- 업무상 최우선: Forecast 및 발주 정확도 향상
- 현행 절차상 1순위 자료취합 시간 단축 → 2순위 부서 간 합의·승인 이력 → 3순위 정확도
- KPI: **월말 재고수량, 월말 재고금액** (목표 재고 대비). 예측 정확도는 Sales OL / SCM OL / 기준예측 3종을 ACT 대비 비교 (D-002)
