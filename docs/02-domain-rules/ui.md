# 규칙: 화면 공통 (R-UI)

최종 갱신: 2026-09-15 · 출처: D-012, 사용자 피드백(2026-09-13 반응형 카드·표 정렬·한글 잘림; 2026-09-14 디자인 언어 D-032~D-039: 카드 표면·KPI 아이콘·사이드바 색; 2026-09-15 D-055 Excel 내보내기)

| ID | 규칙 |
|---|---|
| R-UI-01 | 모든 요약 카드·KPI 숫자는 클릭 시 그 숫자를 구성하는 **행 목록(드릴다운)** 으로 이동한다. 드릴다운은 카드의 필터 조건(기간, 카테고리, 상태)을 URL 쿼리로 유지해 공유·뒤로가기가 된다. |
| R-UI-02 | 메뉴 전환 체감 **1초 이내**. 수단: App Router 클라이언트 네비게이션, 링크 hover 프리페치, TanStack Query 캐시(stale 5분), 첫 화면은 서버 컴포넌트로 데이터 포함 렌더, 무거운 집계는 `analytics` 물리화 뷰(엔진 실행·업로드 후 refresh). 목록은 서버 페이지네이션 + 가상 스크롤. |
| R-UI-03 | 차트는 Apache ECharts. 필수 상호작용: 툴팁(전 시리즈 값), 범례 토글, dataZoom(기간), 예측 구간 음영 + 신뢰구간 밴드, 실제/예측/OL 다중 시리즈, 라인+막대 이중축, 클릭 시 해당 월·품목 드릴다운. 색상은 시리즈 의미 고정(실제=회색, 기준예측=파랑, Sales OL=주황, SCM OL=초록, 발주=보라). |
| R-UI-04 | 재고전개 화면은 트리 그리드(TanStack Table + 가상화): 계층 카테고리→기종→품목(HOC), 열 = 월(과거 12 + 미래 6, 설정 가능). 행: 실제출고, 기준예측, Sales OL, SCM OL, 최종예측(오버라이드), 현재고, 입고예정, 예상 월말재고, DoS, 목표 DoS, 제안 발주량, 확정 발주량. 과거/미래 열 배경 구분, 오버라이드 셀 강조, 편집 이력 저장. **행 순서는 산식(D-050)**: 품목 행 값 = 기말, 자식 행 = 기초 ＋ 입고예정 − 예측 판매 − 추가수요 ＋ 확정 발주 ＝ 기말 — 차감 행은 음수로 표시해 세로로 더하면 기말이 나온다(카테고리 합계 행도 같은 순서, 기초 합은 없음). |
| R-UI-05 | 표는 정렬·필터·컬럼 숨김·**내보내기(CSV·Excel)** 기본 제공. 내보내기는 `components/export/ExportMenu.tsx` 드롭다운 하나로 통일하고, 실제 생성은 `lib/export/sheet.ts`(`exportRows`) 만 쓴다 — 화면마다 Blob 다운로드를 직접 만들지 않는다. 내보내는 범위는 **화면에 보이는 그대로**(정렬·검색·컬럼 숨김 반영). 숫자는 문자열이 아니라 숫자 셀로 넣어 엑셀에서 합계가 되게 하고, CSV 는 BOM(한글 깨짐 방지)+RFC 4180 따옴표, xlsx 는 헤더 고정·열 너비 자동(한글 2칸) (D-055). |
| R-UI-06 | 모든 화면은 한국어. 숫자는 천 단위 구분, 비율은 소수 1자리. |
| R-UI-07 | **카드 높이 동일**: 같은 그리드 행의 카드는 화면 폭과 무관하게 항상 같은 높이. 카드는 `DrillCard` 만 사용하고(`h-full flex-col`, 최소 높이, 힌트 2줄 clamp + 툴팁), 내용 길이로 높이가 달라지게 만들지 않는다. 새 카드 컴포넌트를 만들면 같은 규칙을 적용한다. |
| R-UI-08 | **표 정렬·여백**: 숫자 열은 헤더와 셀 모두 우측 정렬(`tabular-nums`), 텍스트 열은 좌측. 헤더와 셀의 정렬이 다르면 안 된다. 모든 `th/td` 는 좌우 여백 0.5rem 이상(전역 CSS 로 보장) — 인접 열이 붙어 보이는 "들쭉날쭉" 금지. 배지·값 조합은 한 셀 안에서 `whitespace-nowrap`. |
| R-UI-09 | **한글 단어 잘림 금지**: 사이트 전역 `word-break: keep-all`(어절 단위 줄바꿈), 긴 코드/URL 만 `overflow-wrap: break-word`. 표 셀·카드 힌트·설명 문단 어디서도 한글 단어 중간에서 줄이 바뀌면 안 된다. 좁은 폭에서는 줄바꿈 대신 `truncate`+툴팁 또는 2줄 clamp 를 쓴다. |
| R-UI-10 | **비개발자 입력**: 설정·폼에 JSON·코드값을 노출하지 않는다. 키별로 의미 있는 컨트롤(숫자+단위+범위, 월/부서/규칙 선택, 표 편집)을 쓰고 현재값을 사람이 읽는 문장으로 보여준다(`lib/settings/registry.ts`). 새 설정 키를 추가하면 레지스트리에 스펙을 함께 등록한다. 예측 기법 파라미터도 같은 원칙(D-053): `web/lib/forecast/methodRegistry.ts` 의 기법별 스펙(라벨·단위·범위·도움말·선택지)으로 컨트롤을 만들고, 각 기법에 비전문가용 한 줄 설명·"언제 쓰나"를 붙인다. 스펙에 없는 키는 "고급 설정"으로 표시만 하고 화면에서 편집하지 않는다. |
| R-UI-11 | **사이드바 그룹 고정**: 현황 · 계획 · 운영 · 결재 · 데이터 · 관리(하단, 구분선) 6그룹. 새 화면은 반드시 한 그룹에 배속(`lib/auth/roles.ts` MENU_GROUPS), 항목 단위 역할 필터, 빈 그룹은 숨김. 처리 건수(승인 대기·미읽음)는 배지로. 그룹 접기 상태는 사용자별 기억. 선택 메뉴 = 옅은 노랑 배경(#fff1cc)+진갈색 글자, 호버 = 형광 연두 테두리(#7CFF3B)+연한 연두 배경 — 현재 위치와 가리키는 메뉴를 색으로 구분 (D-039). |
| R-UI-12 | **대시보드는 업무 지표**: 재고 건전성(월말 재고금액·DoS·과잉) · 품절 리스크 · 발주 사이클 · 예측 신뢰도 · 주문·배정 운영 5묶음. 시스템 준비 지표(더미·업로드·품목 수)는 관리자 섹션에만, 다른 역할에는 더미가 남아 있을 때 한 줄 경고. 섹션 순서는 역할별(`sectionsForRole`). 색: 노랑=주의, 빨강=즉시 조치, 기준은 코드 주석에 명시 (D-031). |
| R-UI-13 | **디자인 토큰·차트 언어** (`web/lib/design/palette.ts`, `components/charts/theme.ts`): 시리즈 색은 dataviz 검증 팔레트(파랑·주황·아쿠아·노랑·보라…) 고정 슬롯 순, 순환 금지. 카테고리 색 고정(PART 파랑·SUPPLY 아쿠아·OPTION 주황), ABC 는 파랑 순차 램프. 상태색(주의 노랑·조치 빨강)은 시리즈로 재사용 금지, 아이콘/테두리와 함께. 묶음 액센트(재고 파랑·리스크 주황·사이클 보라·예측 아쿠아·운영 노랑). 마크: 막대 ≤24px 끝 4px 라운드, 선 2px, 마커 8px, 격자 hairline, 텍스트는 텍스트 토큰. 카드 3종 — KpiTile(우측 상단 소형 아이콘·큰 숫자·전월 대비·진행바, D-038), DrillCard(compact), ChartCard(제목·한 줄 해석·차트·자세히 링크). 차트는 `MiniCharts`(묶음/스택/가로 막대·도넛·라인) 만 사용, 클릭 드릴다운. 큰 금액은 KPI 에서 억/만 축약 + 툴팁 원값. **카드 표면(`.scm-card`, D-033/D-037)**: 테두리 없음(색 테두리·액센트 띠 금지) — 평상시 우측 하단 방향 drop shadow(2px 3px + 6px 10px) + 액센트 soft→흰색 135° 그라데이션 오버레이 배경, 호버 시 액센트색 outer glow(3px 링 + 우하단 28px 블러) 와 1px 상승. warn/danger 톤은 노랑/빨강 액센트(그라데이션·글로우)로만 구분. 화면 공통 구조(대시보드·예측·발주 계획·재고 배정·일정·영업 주문 전부 동일): KPI 스트립(KpiTile 4~5) → 묶음 섹션(제목 + 카드 열 + 차트 1~2, 차트마다 한 줄 해석) → 전부 드릴다운. 히트맵은 `Heatmap`(파랑 순차 램프, 셀 라벨 = 개수·비중). **차트 반응형(D-047)**: 4열 차트 행은 `.charts-4`(1400px 이상만 4열, 그 아래 2열·1열), `Donut` 은 카드 폭을 측정해 340px 미만이면 범례를 아래로 내리고 링을 가운데에 배치, 링 반지름은 픽셀 계산 — 어떤 폭에서도 잘림·겹침 없음. |
| R-UI-14 | **필터·탭·페이지 이동은 스크롤 위치를 유지한다** (D-054): 같은 화면 안에서 검색 파라미터만 바뀌는 링크(필터 칩, 상태 탭, 이전/다음)는 `<Link scroll={false}>` — 화면 아래쪽 표를 보다가 필터를 눌러도 맨 위로 튀지 않는다. 새 화면으로 가는 링크는 기본(맨 위) 유지. |
