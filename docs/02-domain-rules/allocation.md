# 규칙: 영업 주문과 재고 배정 (R-AL)

최종 갱신: 2026-09-13 · 출처: stage1.md §2 · 구현: migrations/20260913003000_allocation.sql (fn_create_sales_order·fn_confirm/cancel·fn_receive_inbound·fn_auto_allocate·fn_manual_allocate·fn_set_priority·fn_allocation_tick), 화면 /sales-orders, /allocation, /allocation/priority (D-023)
범위 주의: 이 영역은 수요예측이 아니라 **주문/재고 배정 운영** 기능이다. 예측·발주 엔진과 별도 모듈로 본다.

## 주문 상태와 배정 종류

```
검토 요청 ──(임시배정 30일)──► 수주 확정 ──► 확정배정
    │                              ▲
    ├─ 30일 경과 → 자동 만료(복구 불가, 새 검토요청 등록·이전 건 연결)
    ├─ 반려/취소 → 임시배정 해제
    └─ 가용재고 부족 → [부분 임시배정 | 전체 배정 대기] 등록자가 선택
```

| ID | 규칙 |
|---|---|
| R-AL-01 | `검토 요청` 시 해당 수량을 임시배정. 유효기간 **30일**, 연장 불가. 중간에 추가 배정되어도 만료일은 최초 시점 기준. |
| R-AL-02 | 30일 내 수주 미확정 → 자동 만료, 가용재고 복귀. 복구 불가. 재진행은 새 검토 요청 + 이전 건 연결(재요청 이력). |
| R-AL-03 | 가용재고 부족 시 등록자가 `부분 임시배정`(가능 수량만 배정, 부족분 표시) 또는 `전체 배정 대기` 선택. 선택 방식·수량·부족수량·선택자 이력 저장. |
| R-AL-04 | `수주 확정` → 임시배정을 확정배정으로 전환. 확정배정은 30일 만료 없음. |
| R-AL-05 | 주문 상태 변경과 재고 배정은 **하나의 트랜잭션**. 여러 영업사원이 같은 재고를 중복 주문가능으로 보지 않도록. |

## 신규 입고 배정 (품목별 자동/수동)

| ID | 규칙 |
|---|---|
| R-AL-10 | 품목별 신규 입고 배정 방식 `자동 배정` / `수동 배정`. 품목담당자 설정 → 팀장 승인. 설정값·변경자·시각·사유 이력. |
| R-AL-11 | 자동 배정: 입고 시 배정 대기 주문에 자동 배정. 순서 = 사업강화부 우선순위 → 같은 우선순위 내 검토요청 등록 순 → 같은 시각이면 시스템 생성 순 (결정적). |
| R-AL-12 | 부분 임시배정 주문의 부족 수량은 최초 대기 순번 유지. 후속 입고 시 자동 추가 배정. 남으면 부분 상태 유지. |
| R-AL-13 | 자동 배정 시 영업담당자 + SCM 품목담당자에게 알림·이메일 (주문번호, 품목, 배정수량, 남은 부족수량, 시각). |
| R-AL-14 | 수동 배정: 입고돼도 자동 배정 안 함. 품목담당자가 확인 후 **확정배정**(임시 아님, 30일 규칙 미적용). |
| R-AL-15 | 수동 배정 시 등록 순서와 다르게 우선 배정하려면 **사유 필수 + SCM팀장 승인**. 승인 전 실행 금지. |
| R-AL-16 | 우선배정 승인 대기 중 요청 수량을 `승인대기 확보수량`으로 가용재고에서 차감. 만료 없음. 승인 → 즉시 확정배정 전환(재실행 단계 없음). 반려 → 즉시 해제. |
| R-AL-17 | 승인 요청 알림: 팀장에게 즉시 + 처리 전까지 **10분마다 24시간** 반복. 승인/반려 시 즉시 중단. 결과는 요청자·영업담당자에게 알림. 반복 알림 발송 시각·결과 이력. |

## 우선순위 (사업강화부)

| ID | 규칙 |
|---|---|
| R-AL-20 | 사업강화부는 임시배정 건 우선순위 조회·변경 가능. 변경 전후 값·변경자·시각 이력. |

## 만료 알림

| ID | 규칙 |
|---|---|
| R-AL-30 | 임시배정 만료 알림: 만료 **10일, 5일, 3일, 2일, 1일 전**. 만료 당일 자동 해제 + "임시배정이 자동 해제되었습니다" 알림. 대상 = 영업담당자 + SCM 품목담당자. 발송 대상·시각·확인 여부·결과 이력. |

## 확정배정 취소

| ID | 규칙 |
|---|---|
| R-AL-40 | 확정배정 취소·해제는 품목담당자가 팀장 승인 없이 가능. **사유 필수**. |
| R-AL-41 | 확정배정 취소 → 주문도 취소 (배정 대기로 되돌리지 않음). 복구 불가. 재진행은 새 주문 + 이전 주문 연결, 품목·수량·고객 정보 복사 가능. |
| R-AL-42 | 취소 수량 가용재고 복귀. 영업담당자에게 알림 (주문번호, 품목, 해제수량, 처리자, 시각, 사유). |
