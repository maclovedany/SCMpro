# 규칙: 재고 (R-INV)

최종 갱신: 2026-09-17 · 출처: stage1.md §6 §10, 데이터 설명.docx, 회의록, D-007

| ID | 규칙 |
|---|---|
| R-INV-01 | **현재고 = 정상 창고재고만.** 검사 대기재고, 불량·폐기 예정, 서비스센터 보유, 파트너 보유, 이동 중 재고는 제외. |
| R-INV-02 | 입고예정수량은 `창고 입고 완료` 상태가 된 수량만 재고·발주 계산에 반영한다. |
| R-INV-03 | 가용재고(영업부 제공) = 현재고 − 임시배정 − 확정배정 − 승인대기 확보수량 (R-AL). |
| R-INV-04 | 출고 중 **재수출, 기타 출고(트러블·사고·폐각), 데모/투입 후 반환** 은 판매가 아니므로 사용량·트렌드에서 제외. 재고 감소로만 인식한다. 카테고리를 분리 저장해 손실 리포트에 쓴다. |
| R-INV-05 | XCN 연계 부품은 구코드 재고를 HOC 코드 재고에 **합산**한다 (구코드 3개 + 신코드 2개 = 5개). |
| R-INV-06 | 월말 재고수량·재고금액은 KPI. 품목별 목표 재고와 비교한다. 재고금액 계산에는 품목 단가가 필요 — `item_setting.unit_price`(업로드+관리자 입력, 실데이터 전까지 더미, D-007). |
| R-INV-07 | 전월도 재고 = 전월 말 마감 재고. 발주 산출의 시작값. |
| R-INV-08 | 현재고 스냅샷·입고예정·품목 단가는 **파일 업로드와 관리자 화면 입력 둘 다** 지원. 실데이터 전까지 더미값 시드, `is_dummy` 로 표시 (D-007). |
| R-INV-09 | **품목 그룹 재고 현황 (D-058)**: 품목은 제품군 그룹(`app.item_group` — 예: 용지·카드리더기)에 속할 수 있고 그룹은 담당 부서(`owner_dept`)를 가진다. 담당 부서의 대시보드에 그룹별 현재고·가용재고·부족 품목이 표시된다(`analytics.v_group_stock`). 현재고 = 최신 정상 스냅샷(R-INV-01), 가용 = R-INV-02 와 동일 산식. 그룹·소속은 업로드 + 관리자 화면(관리 › 품목 그룹) 이중 경로, 실데이터 전까지 더미. |
