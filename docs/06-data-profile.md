- **집중도**: 상위 20% 품목이 출고량의 PART 95%, SUPPLY 86%, OPTION 97% 차지 → ABC 분류 후 A 품목에 정교한 기법, C 품목은 단순 기법이 합리적.
- **음수 출고** 존재 (반품/조정 추정). 옵션 `EC512048` 2026-07 −1,728 등. 예측 입력에서는 0 으로 클리핑하되 원본은 보존.
- **소모품 월 총량**: 47,840 ~ 77,951. 매년 12월·3월 피크(회계연도 말 3월, 연말 12월) → **연간 계절성 존재**. 추세는 완만한 감소.

## 4. 수명주기 신호

- `bridge_mc_cap.predecessor_model` 106행 전부 채워짐 → 전임기 매핑 확보. 단 예시(MDL222 ← MDL104-5)에서 전임기가 plan_actual 에 없어 전환 곡선 검증 불가.

## 5. 재수출·기타출고 혼입 (Q-006)

데이터에 출고 유형 컬럼이 없어 직접 판별 불가. 옵션 파일은 시트명으로 제외 확인. 소모품·부품은 회사 확인 필요. 이상치(월 평균의 5배 초과 등)를 Bulkdeal/재수출 후보로 자동 플래그하는 것으로 대체.
